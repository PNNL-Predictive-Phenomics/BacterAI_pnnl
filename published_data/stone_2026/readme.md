# Data and analysis from Stone, et al., 2026.

Data and trained models from BacterAI experiments on *Pseudomonas putida* AG5577, functionally equivalent to KT2440, using a continuous-valued chemically-defined medium. The `expt_rounds/` folder contains per-round experimental data, model files, and instrument outputs (*i.e.*, files generated while running BacterAI). The `analysis/` folder contains R scripts for statistical analysis and figure generation based on the data generated by BacterAI.

## Abbreviations

 - Pp = *Pseudomonas putida*
 - AG5577 = strain identifier
 - GEM = Genome-scale metabolic model
 - GPR = Gaussian process regression
 - NN = Neural network
 - CDM = Chemically-defined medium
 - OD = Optical density
 - RGR = Relative growth rate
 - MGR = Maximum growth rate

## Folder structure

### `expt_rounds/`

 - `RoundN/` — Per-round experiment data and models (Rounds 1–4).
 - `experiment_request/` — Dated subdirectories containing instrument data (`data/`), plate maps (`plate_maps/`), and liquid handler worklists (`worklists/`).
 - `config.json` — BacterAI run configuration (batch size, rollout count, growth threshold, etc.).
 - `ingredients.json`, `ingredients.xlsx` — Ingredient definitions including ID, type, concentration ranges, nominal values, and atomic composition.
 - `Batch_growth_predictions_AG5577_3_rounds.xlsx` — GEM-predicted OD time-course data for Rounds 1–3.
 - `stdout_RN.log` — Console output logs from each round.

### `expt_rounds/RoundN/`

 - `results_all.csv` — Full results for the round. The first 12 columns are ingredient concentrations (continuous values). Additional columns include: `type` (policy used), `direction`, `frontier_type` (FRONTIER or BEYOND), `growth_pred` (model prediction at time of selection), `var` (prediction variance), `is_redo`, `round`, `experiment_number`, `feature` (raw delta OD), `bad` (flag for failed experiments), `fitness` (delta OD normalized to plate controls), and `depth`.
 - `results_grow_only.csv` — Subset of `results_all.csv` containing only growth-positive experiments.
 - `batch_meta_*.csv` — Experiment design metadata with ingredient concentrations and search parameters.
 - `batch_dp_*.csv` — Experiment name mappings.
 - `mapped_data_*.csv` — Raw plate reader measurements including `feature`, `bad`, `plate_control`, `plate_blank`, `parent_plate`, `experiment_number`, `strain`, and `environment`.
 - `train_pred.csv` — (Rounds 2+) Neural network predictions with columns for ingredient values, `y_true`, `y_pred`, and `y_pred_var`.
 - `random_train_kickstart_others.csv` — (Round 1) Binary matrix of initial training conditions.
 - `gpr_model/` — Saved GPR model weights (`gpr_model.pth`, `gpr_likelihood.pth`).
 - `nn_models/` — (Rounds 2+) Bagged neural network models (`bag_model_0.pkl` through `bag_model_24.pkl`).
 - `run_metrics.json` — Run performance statistics.

### `analysis/`

 - `calc_depth_function.R` — Utility function to calculate normalized experiment depth (distance from ideal growth conditions).
 - `1_conditions_tested.R` — Analysis of experimental conditions across rounds, including depth calculations and bootstrap statistics.
 - `1b_checking_controls.R` — Positive control quality assessment and re-normalization of fitness values.
 - `2_conditions_vs_fitness.R` — Relationships between medium components and fitness, including LASSO regression and quantile regression.
 - `3_growth_curve_analysis.R` — Growth curve smoothing, maximum growth rate estimation, and diauxic shift detection.
 - `4_gem_output_vs_obs.R` — Comparison of GEM-predicted vs. observed growth (delta OD and maximum growth rate).
 - `positive_ctrls.csv` — Average and SD of positive control delta OD per round.
 - `positive_ctrls_mgr.csv` — Average and SD of positive control maximum growth rates per round.
 - `max_growth_rates.csv` — Maximum relative growth rates per experiment (`round`, `experiment_number`, `solution_id`, `mgr`, `mgr_time`).
 - `delta_od_for_gem_compare.csv` — Ingredient concentrations with measured delta OD for GEM model comparison.
