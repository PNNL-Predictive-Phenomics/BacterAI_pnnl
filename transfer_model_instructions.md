# Transfer Learning (RF) Instructions

This document describes how to run BacterAI in Python-only RF transfer-learning mode.

## Mode Summary

- Enabled only when `--transfer-learning` is provided.
- Round 1 trains native Python transfer RF variants (`m0`, `m1`, `m2`, `m3`, plus ensemble).
- Round 1 recommendation uses EI acquisition.
- Round 2+ continues with the native MDP simulation loop and can warm-start from the Round 1 transfer artifact.
- No external R/rpy2 runtime dependency.

## Run Transfer Learning

```bash
bacterai run <experiment_path> --transfer-learning
```

Example:

```bash
bacterai run tests/test_rf_experiment --transfer-learning
```

## Feature Overlap Requirement

Transfer-learning uses bundled pputida feature names and intersects them with experiment ingredients.

- At least 2 overlapping features are required.
- If overlap is below 2, the run fails with a feature-overlap error.

## Outputs

Round folder outputs:

- `batch_meta_<timestamp>.csv`: recommendation batch metadata.
- `batch_dp_<...>.csv`: DP export.
- `run_metrics.json`: selected source and transfer metrics.
- `transfer_rf_model.pkl`: Round 1 transfer artifact.

Experiment root outputs:

- No automatic drift comparison reports are generated by the runtime application.
- If you need comparison reports, run outcome-comparison analysis as a separate, offline workflow.
